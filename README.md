# 2D-spill-halv-rsprosjekt-VG2
2D platformer spill jeg skal lage første halvår av VG2

Dette er et 2D spill som jeg har brukt uke 45 og 46 på å lage, det skal være flere baner som blir vanskeligere med hver bane.
Det ligger kildeliste for grafikk på bunnen av READMEen.


Spillet er et simpelt platformer spill, målet er å komme fra venstre side til høyre, men det er hindringer i veien som
stopper deg fra å gå rett fram.


Her er programmene jeg bruker for oppgaven:
Unity (6000.3.9f1)
VSCode (2026)
Visual Studio
GitHub
